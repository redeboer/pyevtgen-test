```{eval-rst}
.. automodule:: pyevtgen

.. py:data:: DECAY_FILE
   :type: pathlib.Path

   Default EvtGen decay table that is bundled with the package.

.. py:data:: PARTICLE_TABLE
   :type: pathlib.Path

   Default EvtGen particle table that is bundled with the package.

.. py:data:: PYTHIA8_XML_DIR
   :type: pathlib.Path

   Pythia8 settings and particle data, used by EvtGen's ``PYTHIA`` decay model.

.. py:data:: EVTGEN_VERSION
   :type: str

   Release tag of EvtGen that the package is built with.

.. py:data:: HEPMC3_VERSION
   :type: str

   Version of HepMC3 that the package is built with.

.. py:data:: PYTHIA8_VERSION
   :type: str

   Version of Pythia8 that the package is built with.
```
